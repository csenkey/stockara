# Backtest Support With Shadowed Portfolios

Status: Proposed.

Canonical files:

- `requirements.md`
- `design.md`
- `backlog.md`

This feature validates whether Stockara recommendations improve simulated portfolio outcomes versus hold-only and ETF baselines. It is not the real-user portfolio management feature.

When updating this feature, keep requirements, design, and backlog aligned. S3 is the canonical storage strategy for decision-grade backtest data and run artifacts.
